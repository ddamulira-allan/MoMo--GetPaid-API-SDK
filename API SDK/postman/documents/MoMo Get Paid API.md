## Quick Start

1. Open the **MoMo Get Paid** environment and fill in your credentials:
   - `apiUser` — your API user UUID from the MoMo Developer Portal
   - `apiKey` — your API key secret
   - `subscriptionKey` — Collection product subscription key
   - `disbursementSubscriptionKey` — Disbursement product subscription key
2. Set `targetEnvironment` to `sandbox` (default) or `production`.
3. Run **Generate Access Token** — the `accessToken` variable is saved automatically.
4. You're ready to call any endpoint.

> **Tip:** `accessToken`, `requestId`, and `requestIdRefund` are managed automatically by pre/post-request scripts. You don't need to set them manually.

## Authentication

### 1. Generate Access Token

| | |
|---|---|
| **Method** | `POST` |
| **URL** | `{{baseUrl}}/collection/token/` |
| **Auth** | HTTP Basic (`{{apiUser}}` : `{{apiKey}}`) |

Generates a Bearer access token. The token lifetime is returned in the `expires_in` field (seconds).

**Required Header**

| Header | Value |
|---|---|
| `Ocp-Apim-Subscription-Key` | `{{subscriptionKey}}` |

**Example Response**

```json

```

> **Script:** The post-response script automatically saves `access_token` to `{{accessToken}}` so all subsequent requests are authenticated without any manual steps.

## Collection

### 4. Request to Pay

| | |
|---|---|
| **Method** | `POST` |
| **URL** | `{{baseUrl}}/collection/v1_0/requesttopay` |
| **Auth** | Bearer `{{accessToken}}` |
| **Success** | `202 Accepted` (no response body) |

Initiates a Request-to-Pay transaction. The payer receives a prompt on their phone to approve the payment.

**Required Headers**

| Header | Value | Notes |
|---|---|---|
| `Authorization` | `Bearer {{accessToken}}` | |
| `X-Reference-Id` | `{{requestId}}` | UUID — auto-generated by pre-request script |
| `X-Target-Environment` | `{{targetEnvironment}}` | |
| `Ocp-Apim-Subscription-Key` | `{{subscriptionKey}}` | |
| `Content-Type` | `application/json` | |
| `X-Callback-Url` | `{{callbackUrl}}` | Optional — disabled by default |

**Request Body**

```json
{
  "amount": "100",
  "currency": "EUR",
  "externalId": "ext-ref-001",
  "payer": {
    "partyIdType": "MSISDN",
    "partyId": "{{msisdn}}"
  },
  "payerMessage": "Payment for order #001",
  "payeeNote": "Order #001 payment received"
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `amount` | string | ✅ | Amount to charge |
| `currency` | string | ✅ | ISO 4217 currency code (e.g. `EUR`, `UGX`) |
| `externalId` | string | ✅ | Your own transaction reference |
| `payer.partyIdType` | string | ✅ | Always `MSISDN` |
| `payer.partyId` | string | ✅ | Payer's mobile number |
| `payerMessage` | string | ✅ | Message shown to the payer |
| `payeeNote` | string | ✅ | Internal note for the payee |

> **Script:** The pre-request script auto-generates a UUID and sets it as both `{{requestId}}` and the `X-Reference-Id` header. Use this same `requestId` to poll the status.

## Typical Workflows

### Payment Flow

```
1. Generate Access Token
        ↓
2. (Optional) Check Account  →  verify MSISDN is active
        ↓
3. (Optional) Check Names    →  confirm payer identity
        ↓
4. Request to Pay            →  202 Accepted, saves {{requestId}}
        ↓
5. Get Request to Pay Status →  poll until SUCCESSFUL or FAILED
        ↓
6. Send Delivery Notification →  notify payer of receipt
```

### Refund Flow

```
1. Generate Access Token  (if token expired)
        ↓
2. Refund                 →  202 Accepted, saves {{requestIdRefund}}
                              set referenceIdToRefund = original {{requestId}}
        ↓
3. Get Refund Status      →  poll until SUCCESSFUL or FAILED
```

## Error Handling

All endpoints return standard HTTP error codes. The SDK wraps errors with context:

```
[MoMoSDK] <operation> failed (HTTP <status>): <message>
```

| HTTP Status | Meaning |
|---|---|
| `400` | Bad Request — invalid parameters |
| `401` | Unauthorized — invalid or expired token |
| `404` | Not Found — resource (requestId, MSISDN) does not exist |
| `409` | Conflict — duplicate `X-Reference-Id` |
| `500` | Internal Server Error — MoMo platform issue |

> **401 Tip:** Re-run **Generate Access Token** to refresh `{{accessToken}}` and retry.
